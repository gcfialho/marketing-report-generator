# Original 2025 version (archived)

These are the outputs of the first version of this project, kept for comparison with the current
pipeline. **Their conclusions are not supported by the data and should not be cited:**

- the report and the slide deck claim "+25% registrations and +30% ROI", but the export has no
  cost or spend data, so no ROI can be computed;
- Social Media is called "complete budget waste" on the basis of 0 conversions out of 14 prospects.
  The current pipeline puts every channel on *Hold* for this export and gives Social Media a 95%
  upper bound of 21.5%.

The current, reproducible outputs are in [`examples/`](../../examples/).
